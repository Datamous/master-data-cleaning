# Master Data Cleaning: Companion Code and Data

This repository holds the Jupyter notebooks and data files for the book
**_Master Data Cleaning: A Hands-On Beginner's Guide with Python, pandas & NumPy_** by Datamous.

Each chapter has its own folder. Inside you'll find a notebook with every code example from the
chapter (already run, so you can compare your results) and the small data files those examples use.
Everything here runs on **pandas 3** and is free to use, with or without the book.

## About the book

A beginner's guide to cleaning messy data with Python: missing values, duplicates, outliers,
inconsistent text, mixed date formats, merging and reshaping, ending with a capstone project that
cleans a messy 200-order sales file. 12 chapters, 116 quiz questions with explained answers, every
example tested on pandas 3.

## How to use these files (step by step)

You only need to do steps 1 and 2 once.

### 1. Install Anaconda

Anaconda installs Python, pandas, NumPy and Jupyter in one go.

1. Go to <https://www.anaconda.com/download> and download the installer for your computer
   (Windows, macOS or Linux).
2. Run the installer and keep all the default settings.

Chapter 1 of the book explains this in more detail and shows how to check that it worked.

### 2. Download this repository

1. Near the top of this page, click the green **Code** button.
2. Click **Download ZIP**.
3. Find the downloaded file (usually in your **Downloads** folder), right-click it and choose
   **Extract All…** (Windows) or double-click it (macOS).
4. Move the extracted folder, `master-data-cleaning-main`, somewhere easy to find, such as your
   **Documents** folder.
5. Open it and check you can see `chapter-01`, `chapter-02` and so on. If you see another folder called
   `master-data-cleaning-main` instead, that's normal on Windows: use that inner folder.

If you already use Git, you can clone the repository instead:

```console
git clone https://github.com/Datamous/master-data-cleaning.git
```

### 3. Open a chapter notebook

1. Start **Jupyter Notebook**. On Windows, search the Start menu for "Jupyter Notebook". On macOS,
   open **Anaconda Navigator** and click **Launch** under Jupyter Notebook.
2. Your browser opens and shows your files. Click your way into
   `Documents` → `master-data-cleaning-main` → the chapter folder you want, for example `chapter-06`.
   (On many Windows computers, Documents is inside the **OneDrive** folder.)
3. Click the notebook file (for example `chapter-06.ipynb`) to open it.
4. Click inside the first code cell and press **Shift + Enter** to run it. Keep pressing
   **Shift + Enter** to work through the chapter.

To start a notebook fresh, use **Kernel → Restart Kernel and Clear Outputs of All Cells**, then run
the cells again from the top.

## Software versions

The code was tested with Python 3.14, pandas 3.0 and NumPy 2.5. Python 3.12 or later is recommended; 3.11 also works.
If you use pandas 2.x instead, almost everything still runs; the main visible difference is that
text columns show their type as `object` instead of `str`.

If you don't use Anaconda, install the libraries with pip:

```console
pip install -r requirements.txt
```

## Notes

- Some notebooks create files as they run (for example, Chapter 5 saves `employee_data.csv`, and
  Chapter 12 saves `orders_clean.csv`). They appear in the chapter folder and are safe to delete.
- The Chapter 12 data is generated by `chapter-12/make_data.py`. You don't need to run it, because the
  data files are already included, but it shows how the messy dataset was built.
- All data in this repository is made up for teaching. Any resemblance to real people or companies is
  coincidental.
